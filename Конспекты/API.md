> [!info] Определение
> **API (Application Programming Interface)** — это **программный интерфейс, позволяющий различным приложениям взаимодействовать между собой** без прямого вмешательства в код друг друга. Расшифровка названия: Application — приложение или сервис, Programming — программный доступ, Interface — интерфейс взаимодействия.
